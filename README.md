## About 📱

iMody is an innovative iOS app designed specifically for women during their menstrual cycle. Using an intelligent mood detection system, iMody helps users understand and manage their emotional state through a series of thoughtfully crafted questions and personalized music recommendations.

## Features ✨

- **Smart Mood Detection**: Through carefully designed questions, iMody analyzes your current emotional state
- **Personalized Music Therapy**: Direct integration with Apple Music to provide mood-specific playlists
- **Beautiful UI/UX**: Smooth animations and calming gradient backgrounds that adapt to your mood
- **Progress Tracking**: Ability to go back and modify answers for more accurate results
- **Privacy-Focused**: All data stays on your device

## How It Works 🎯

iMody uses a sophisticated scoring system to categorize your mood into four main states:

- 😊 **Happy**: Positive and energetic state
- 😔 **Sad**: Emotional and reflective state
- 😠 **Stress**: Tense or overwhelmed state
- 😶 **Foggy**: Unclear or scattered state

Based on your responses, the app provides:
1. A personalized mood analysis
2. Motivational messages tailored to your current state
3. Curated music playlists to help improve your mood

## Technical Details 🛠

- Built with SwiftUI
- Implements MVVM architecture
- Uses Apple Music API integration
- Features smooth animations and transitions
- Implements adaptive UI elements

## Requirements 📋

- iOS 15.0+
- Xcode 13.0+
- Swift 5.5+
- Apple Music subscription (for playlist features)
